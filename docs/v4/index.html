The Basics of Logifunge v4

A Logifunge v4 program is a grid of instructions. The instruction pointer begins at the upper-left and travels right, wrapping across the grid's edges. Direction commands can turn the pointer, so the order of execution is determined by the path rather than by the visual order of the source alone.

Each instruction executes once when visited. Spaces do nothing. The stack stores values between instructions, and % ends the program. The IDE can run the complete path or reveal it one step at a time.

A first program

[65] = %

Push 65, print A, then stop.

Stack Arithmetic

Values use a postfix, last-in-first-out stack: the most recently pushed value is always consumed first. Two-value operators still combine their operands in push order, though — 23-. produces -1 because 2 was pushed before 3, so the subtraction reads as 2 minus 3, not 3 minus 2.

23- . %
stack: [] -> [2] -> [2, 3] -> [-1]
output: -1

Digits push single values and [n] pushes an integer literal. : duplicates the top value, \ swaps the top two, and $ discards the top value. Popping an empty stack returns 0 instead of erroring for most instructions — but a few, such as packing and indexed swaps, require a specific number of values up front and report an error rather than quietly filling in zeros.

99*76*+ . %
output: 123

Movement and Decisions

> < ^ v set right, left, up, and down movement. ? chooses randomly and # skips one cell. _ pops a value and goes right for zero or left for nonzero. ! goes down for zero or up for nonzero.

Named loops turn those movement rules into reusable control flow. The closing marker pops its condition and returns to the matching opening marker only when nonzero.

>5{[count]:.1-:}[count]$%

This prints a countdown. The loop is a path through the grid, not a separate block construct.

Logic Gates

Logifunge's logic instructions are the language's central departure from classic Befunge. They treat zero as false, nonzero as true, and return a single bit.

00@. 01@. 10@. 11@. %
output: 0 1 1 0
CommandOperation
& | @AND, OR, XOR
~NOT
N R XNAND, NOR, XNOR

For a half adder, duplicate the inputs, use XOR for the sum, and AND for the carry:

11::@.\&.%
output: 0 1

Text, Pixels, and the Program Grid

. prints a number and = prints ASCII. Quotes enable string mode, where each cell's character value is pushed.

[72]=[105]=[33]=%
output: Hi!

Pixel write , pops x, y, and a value. Pixel read ' pops x and y and pushes the pixel at those coordinates. The v4 IDE displays pixel writes on its canvas.

The commands g and p access the program grid itself: get a cell at x,y or put a value there. This permits self-reading and self-modifying programs.

Self-modifying code

p can write to a cell before the IP has run it, which means the instruction that eventually executes there may not match what's printed in the source. Here's a small example laid out by position:

position:   0    1    2    3    4    5    6    7    8
character:  "    5    "    6    0    p    2    .    %

Cells 0–2 use string mode to push the character code for 5. Cells 3–4 push 6 and 0, the coordinates of the 2 at position 6. p pops those three values and overwrites position (6, 0) with 5 — before the IP has reached it. So when the IP steps onto position 6, it runs the new instruction:

"5"60p2.%
output: 5

Subroutines and Loops

Version 4 uses explicit subroutine markers. D[name] defines a routine, C[name] calls it, and r returns. Normal flow skips a definition, while a call jumps to its body and saves the return address separately from the data stack.

1 C[inc] . %D[inc]1+r
output: 2

Loops use {[name] and }[name]. Names can be written horizontally or vertically through the grid.

Packing and Memory

Packing lets several bits travel as one value without losing their width. ( packs the requested number of values, and ) unpacks the typed value without needing a separate count.

00001 5 ( ) ..... %
output: 1 0 0 0 0

M selects a memory index, S stores the top value, and L loads it.

5M 7S L . %
output: 7

W swaps values at two stack indexes, where index 0 is the top.
