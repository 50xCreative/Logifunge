The Basics of Logifunge v1

Logifunge v1 is a two-dimensional language. Your source is a grid of characters, and the instruction pointer starts in the upper-left corner moving right. Every step executes the cell under the pointer and then advances one cell in the current direction.

The pointer may move in four directions and wraps around the edges. A space is a no-op, so spaces can be used to lay out a program without changing its behavior. The program ends when it reaches % or exceeds the IDE's step limit.

Your first program

This program pushes 65, prints it as an ASCII character, and stops.

[65] = %

The Stack

Values are kept on one last-in, first-out stack. Digits push their numeric values. A bracketed literal such as [42] pushes a larger number. If an instruction pops an empty stack, it receives 0.

Arithmetic is postfix. In 23-., the stack contains 2 below 3, so the subtraction is 2 minus 3.

23- . %
stack: [] -> [2] -> [2, 3] -> [-1] -> []
output: -1

: duplicates the top value, \ swaps the top two values, and $ discards the top value.

Movement and Decisions

The commands > < ^ v set the pointer's direction. ? chooses a random direction, and # skips over the next cell. The conditional commands pop a value: _ goes right for zero and left for nonzero; | goes down for zero and up for nonzero.

These rules make loops possible. A path such as >< continually reverses direction, while a conditional can escape a loop after consuming a sentinel value.

>5{[count]:.1-:}[count]$%

Named loops use {[name] and }[name]. The closing marker pops its condition and jumps back when that value is nonzero.

Logic Gates

In v1, logic instructions treat zero as false and nonzero as true, returning a single bit. Each binary gate pops its two operands and pushes its result.

00@. 01@. 10@. 11@. %
output: 0 1 1 0

Use : when one input needs to feed more than one gate. This makes small circuits such as half adders possible.

Output and the Grid

. prints a decimal number and = prints an ASCII character. String mode, entered with ", pushes the ASCII value of each character until the next quote.

[72]=[105]=[33]=%

, writes a pixel by popping x, y, and a value. ' reads a pixel at x,y. The commands g and p read and modify the program grid itself, allowing self-modifying programs.

Subroutines

Version 1 uses the colon in two ways. A bare : duplicates the stack top, but :[name] defines a subroutine. Its body ends at r, and ordinary flow skips over the definition. Call it with ;[name]; the return address is kept on a separate return stack.

1 ;[inc] . % :[inc]1+r
output: 2

This overloaded syntax is a historical feature of v1. Later versions separate definition and call markers.
